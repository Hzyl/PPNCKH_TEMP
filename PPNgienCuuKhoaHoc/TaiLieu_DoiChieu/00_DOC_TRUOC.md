# Tài liệu đối chiếu môn Phương pháp nghiên cứu khoa học

Trong mỗi thư mục học kỳ, mở file Word có tên bắt đầu bằng **00_BaoCao** để đọc bài song song với tài liệu bên dưới. Hai file Word ở đây là bản sao để đối chiếu tại thời điểm gom nguồn.
